## 0. 一页纸

### 0.1 这是什么

**MCP REST Bridge** —— 把上游已有的 REST 服务**包装成 MCP Server** 供 AI 客户端调用，附带一套中文管理控制台。

| 维度 | 定稿 |
| --- | --- |
| 管理面 | REST `/api/v1/**`，**62 个接口**（阶段 0 落地 **30 个**，**无用户概念**） |
| 数据面 | MCP `POST /mcp`（**三形态**：HTTP+SSE / Streamable stateful / Streamable stateless） |
| 管理面 MCP | `POST /admin/mcp`（**阶段 3**，见 [`管理面MCP设计.md`](./管理面MCP设计.md)） |
| 多租户 | **17 张表**（15 核心 + 2 可选），共享表 + `tenant_id` 行级隔离 |
| 数据库 | **MySQL 8.0.30+** / **PostgreSQL 13+** 双库 |
| 协议版本 | `2024-11-05` / `2025-03-26` / `2025-06-18` / `2025-11-25` / `2026-07-28` |

### 0.2 技术栈（🔒 锁定）

`JDK 25` + `Spring Boot 4.1.1` + `Tomcat 11.0.24` + `Maven 3.9.16` + `MyBatis-Plus 3.5.17` + `Flyway` + `io.modelcontextprotocol.sdk:mcp 2.1.0`；前端 JS/Vue3；中间件 MySQL 8.0.36 / PG 14 / Redis 7.4 / MinIO（MinIO **本期不连**）。

## 1. 红线（**19 条，不可违反**）

> 开发时逐条对照。违反任一条 = 该 PR 不合并。

### 1.1 安全（8 条）

| # | 红线 | 出处 |
| --- | --- | --- |
| R1 | 形态一的 `sessionId` **必须与主体绑定**；跨主体 → 对外一律 **`404`**（不是 403，防探测） | A1 |
| R2 | 阶段 0 免鉴权**必须**受四道护栏：显式开关 / **`prod` 拒绝启动** / 留骨架 / `jwt` 模式验人 | A2 |
| R3 | `url → blob` 的 SSRF 防护**全套做**：8 条要求 + 8 条验收；端口受 `SSRF_ALLOWED_PORTS` 约束 | A3 |
| R4 | 敏感值**只出 `***`**；写回 `***` = **保留原值**；`sensitive` **默认 `1`** | A4 |
| R5 | 密码 **BCrypt cost 12** + `VARCHAR(255)` + ≥8 位含字母数字 + **5 次失败锁 15 分钟** → `42301` | A5 |
| R6 | token 明文**内嵌租户标识** + CSPRNG 熵；**取消跨租户全局唯一索引** | A6 |
| R7 | api-key 过期时间**缺省即最严**：`expiresAt` 不填 → **拒绝**（绝不"缺省永久"）；页面选「永不过期」需**红字警告 + 写审计** | D8 / §12.4 |
| R8 | **列表过滤 ≠ 鉴权** —— 权限**必须**在工具处理器内再校验（SDK 过滤掉的原语**仍可直调**） | D1 |

### 1.2 数据一致性（7 条）

| # | 红线 | 出处 |
| --- | --- | --- |
| R9 | 并发写一律 **CAS**（`UPDATE … WHERE version=?`），影响行数 0 → **`40901`** | B1 |
| R10 | `PUT` / 删除**必带 `version`**（例外：`mcp_config` / `mcp_user`） | B2 |
| R11 | 软删读路径的 `deleted_seq=0` **由拦截器强制追加**，不许手写（人会忘） | B3 |
| R12 | 跨租户清理走**专用 Mapper**（独立 SqlSession）+ 清理专用白名单 | B4 |
| R13 | 异步任务**显式入参 `tenantId`**；**禁用 `TaskDecorator`** | B5 |
| R14 | 雪花 `workerId` 由 env/StatefulSet 提供 + 启动校验唯一性 + 时钟回拨 >5ms 拒绝启动 | B9 |
| R15 | 隔离级别 **RC** 显式设置 + CI 断言；唯一/比较列用 **`utf8mb4_0900_bin`** | B8 / B6 |

### 1.3 协议与契约（4 条）

| # | 红线 | 出处 |
| --- | --- | --- |
| R16 | 三形态**不能各自挂 `POST /mcp`**（后注册者静默失效）⇒ 统一 `EraRouterServlet` 按 `Mcp-Method` 分发；🔴 **反代不得剥该头、不得改写路径前缀** | D6 / D9 |
| R17 | **能力是构建期快照**：工具集空 ⇒ **不下发 `tools` 键**（不是 `{}`）；非空 ⇒ `{"listChanged": false}`；按租户构造；握手后定格 | D4 / #13 |
| R18 | 工具名**必须自己校验**（SDK 零校验）：`^[A-Za-z0-9_\-.]+$`，1~128，**中文会被拒** → `40001` | D2 |
| R19 | 上游默认超时 **15s**（SDK 客户端 20s 是硬上限）；`logging` **只接受 `setLevel`、不推 `notifications/message`** | D7 / D3 |

## 3. 参数语义（最容易做错，单列）

**三态 + 1 派生**（决策 #26 / #27）：

| 层面 | `required` | `nonEmpty` | `value` | `overridable` |
| --- | --- | --- | --- | --- |
| **服务级鉴权** | **恒 `1`**（最终值必须存在） | **恒 `0`**（允许空串） | 可空 | **派生 = `(value IS NULL)`** |
| **工具级参数** | 可配 `0/1` | 可配 | 可空 | 同上 |

**三条实现要求**：
1. `overridable` **不得独立读写**，一律由 `value IS NULL` 推导；
2. `value` 的 **`NULL` 与 `''` 不等价** —— `NULL` = 动态（模型可见），`''` = 固定空值（不进 `inputSchema`）；**禁止把 `''` 归一成 `NULL`**（否则凭据会意外进模型上下文）；
3. `value` 非空 ⇒ 该参数**根本不进 `inputSchema`**。
