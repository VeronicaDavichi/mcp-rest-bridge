5. 沟通语言中文；主人不喜欢长篇估算，喜欢"结论先给 + 取舍直说"；
6. **接口文档是唯一契约来源**：`docs/前后端交互接口设计.md`（管理面）+ `docs/MCP-Server对外接口设计.md`（对外 MCP）。
