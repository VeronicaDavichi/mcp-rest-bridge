## 1. 目标、边界与不做什么

**目标**：把设计稿里每一个可交互元素，翻译成前后端可验收的 HTTP 接口契约，作为初期规划的联调基线。

**做**：
- 页面 → 功能点 → 接口 的双向可追溯（第 4 章矩阵 + 第 7 章逐接口「对应页面元素」）
- 请求/响应字段、校验规则、错误码、分页与文件上传约定
- 未设计页面的缺口清单与占位接口签名

**不做（本期）**：
- 数据库表结构、索引、迁移脚本
- 管理端登录、用户、角色、权限点的具体设计（只留占位）
- MCP 协议端点的完整实现细节（只标注待定）
- 前端组件划分与状态管理设计

## 3. 术语与领域模型

| 术语 | 说明 |
| --- | --- |
| **服务 Service** | 一个被代理的 HTTP 服务（如 OA 系统），含名称、简称、URL 前缀、描述、标签、鉴权参数 |
| **工具 Tool** | MCP 暴露给模型调用的能力，对应服务下的一个 HTTP 接口；含 MCP 名称、描述、方法、参数映射 |
| **资源 Resource / 提示词 Prompt** | MCP 的资源与提示词概念，首页有计数，但**无功能设计** |
| **MCP 参数名** | 暴露给模型看的参数名，可与原始 HTTP 参数名不同 |
| **鉴权参数** | 服务级别的参数映射（Cookie/Header/Query/Body…），把模型给的参数注入到真实请求 |
| **导入 Import** | 上传 OpenAPI/Swagger 文件 → 检查候选接口 → 执行导入 → 查看结果 的四步流程 |

### 3.1 核心对象字段（供接口引用）

**Service**
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `id` | string | - | 服务 ID |
| `name` | string | 是 | 服务名称，卡片标题 |
| `shortName` | string | 是 | 简称，≤4 字符 |
| `urlPrefix` | string | 是 | URL 前缀，如 `http://192.168.1.11/test` |
| `description` | string | 否 | 描述，卡片正文，超长两行省略 |
| `enabled` | boolean | 是 | 启用状态（对应卡片圆点，见 A4） |
| `tags` | Tag[] | 否 | 标签列表 |
| `authParams` | AuthParam[] | 否 | 鉴权参数映射 |
| `toolCount` | number | - | 工具数量（列表页可选返回） |
| `createTime` / `updateTime` | string | - | 时间 |

**Tag**：`{ id, name, color? }`

**AuthParam**（设计稿列：位置 / 原参数名 / MCP 参数名 / MCP 对该参数的描述，行间用「和/或」连接）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `location` | enum | `COOKIE` / `HEADER` / `QUERY` / `BODY_RAW` / `BODY_JSON` / `FORM_DATA`（下拉原项：Body (Raw)、Body (Json)、Cookie、Form Data、Header、Query Parameter） |
| `originName` | string | 原参数名，如 `token` |
| `mcpName` | string | MCP 参数名，如 `sso_token` |
| `description` | string | MCP 对该参数的描述，如「系统统一认证单点登录的 token」 |
| `relation` | enum | `AND` / `OR`，与上一行的连接关系（设计稿左侧「和/或」） |

**Tool**
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 工具 ID |
| `name` | string | MCP 工具名，列表首列 |
| `description` | string | 工具描述，模型可见 |
| `httpMethod` | enum | `GET`/`POST`/`PUT`/`DELETE`/`PATCH`/`HEAD`/`OPTIONS` |
| `serviceId` / `serviceName` | string | 所属服务（工具详情下拉「未选择服务」） |
| `originPath` | string | 原始 HTTP 路径 |
| `mcpPath` | string | 改写后暴露的路径（规则见 A7） |
| `enabled` | boolean | 状态开关 |
| `pathParams` | Param[] | 路径参数（参数名与行数由路径自动生成） |
| `headers` / `cookies` / `queryParams` | Param[] | 请求头 / Cookie / Query 参数，三者结构一致 |
| `requestBody` | object | `{ type: none\|formData\|json\|xml\|html\|plainText\|blob, params: Param[], example: string }` |
| `responses` | object | `{ success: ResponseDef, failure?: ResponseDef }`，成功/失败两态 |
| `curlPreview` | string | 详情右侧 `curl -X POST ...` 预览 |

**Param**（请求头/Cookie/Query/请求体统一结构）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 原参数名（路径参数自动生成，不可编辑） |
| `mcpName` | string | MCP 参数名 |
| `type` | enum | `string`/`string[]`/`number`/`boolean`/`object`/`BLOB_URL`/`BLOB_BASE64` |
| `required` | boolean | 必填（设计稿圆点） |
| `allowEmpty` | boolean | 对应设计稿「非空」列；`false` 时允许空值：String 传空字符串、blob 传 0 大小文件 |
| `description` | string | MCP 对该参数的描述 |

**ResponseDef**：`{ status: number, contentType, bodyType: json|xml|html|plainText|blob, schema/example, description }`

## 5. 通用约定

| 项 | 约定 |
| --- | --- |
| 基础路径 | `/api/v1`（占位，随你的规范调整） |
| 编码 | 请求/响应 `application/json; charset=utf-8`；上传用 `multipart/form-data`；下载用 `application/octet-stream` |
| 字段命名 | JSON 统一小驼峰；ID 一律字符串 |
| 时间 | 见 A12 |
| 分页 | 见 A2；列表响应结构 `{ total, pageNum, pageSize, list }` |
| 排序 | `sort=field,asc\|desc`，默认 `updateTime,desc` |
| 幂等 | 重复提交创建类接口以 `name`（服务）/`name`（工具）唯一约束兜底，冲突返回 409 |
| 批量操作 | 统一 `{ ids: string[] }`，返回 `{ successCount, failedCount, failed: [{ id, reason }] }` |
| 删除语义 | 默认物理删除；被工具引用的服务删除时返回 409 并提示先清理工具 |
| 空值 | `allowEmpty=false` 的 String 传空字符串；blob 传 0 大小文件（设计稿注释原文） |

### 5.1 建议错误码（占位，等 A1 规范替换）

| 业务码 | HTTP | 场景 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 40001 | 400 | 参数校验失败（含简称 >4 字符） |
| 40100 | 401 | 未认证（管理端鉴权定了再启用） |
| 40300 | 403 | 无权限 |
| 40400 | 404 | 对象不存在 |
| 40900 | 409 | 名称重复 / 唯一约束冲突 |
| 41300 | 413 | 上传文件超限（>10MB） |
| 41500 | 415 | 文件类型不支持 |
| 42200 | 422 | OpenAPI/Swagger 解析失败 |
| 42400 | 424 | 测试路径探测失败（连接超时、DNS 失败） |
| 42900 | 429 | 触发限流 |
| 50000 | 500 | 服务端内部错误 |

## 7. 接口详情

> 响应示例统一用 A1 占位封装；`data` 内部结构为契约本体。

### 7.1 首页

#### 1) GET `/api/v1/dashboard/overview`
- **用途**：渲染「数据监控」卡片计数。
- **响应**
```json
{ "code": 0, "message": "ok", "data": { "serviceCount": 5, "toolCount": 10, "resourceCount": 2, "promptCount": 1 } }
```
- **对应页面元素**：P0 「服务 5 / 工具 10 / 资源 2 / 提示词 1」。

#### 2) GET `/api/v1/dashboard/traffic`
- **用途**：渲染「流量监控」折线。
- **Query**：`range`（`24h`/`7d`/`30d`，默认 `7d`）、`granularity`（`hour`/`day`）
- **响应**
```json
{ "code": 0, "message": "ok", "data": {
  "points": [ { "time": "2026-10-13", "requests": 1280, "successRate": 0.98, "avgLatencyMs": 142 } ],
  "summary": { "totalRequests": 8920, "successRate": 0.97, "avgLatencyMs": 150 }
} }
```
